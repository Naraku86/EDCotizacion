# Contributing / Contribuir

**English** — Bug reports and suggestions are welcome in
[Issues](https://github.com/OWNER/EDCotizacion/issues). For security problems follow
[SECURITY.md](SECURITY.md) instead. Pull requests: keep them focused, include tests (`mvn verify`
must pass) and follow the conventions in [docs/en/development.md](docs/en/development.md). Issues can
be written in English or Spanish.

**Español** — Los reportes de errores y sugerencias son bienvenidos en
[Issues](https://github.com/OWNER/EDCotizacion/issues). Para problemas de seguridad sigue
[SECURITY.md](SECURITY.md). Pull requests: enfocados en un solo cambio, con pruebas (`mvn verify` debe
pasar) y siguiendo las convenciones de [docs/es/desarrollo.md](docs/es/desarrollo.md). Los issues
pueden escribirse en español o inglés.
